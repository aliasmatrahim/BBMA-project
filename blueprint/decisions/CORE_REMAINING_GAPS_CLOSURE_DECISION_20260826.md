## 1. Evidence hierarchy used

Closure follows this order:

1. user-supplied `Oma ally BBMA - AL.pdf` — primary operational source;
2. user-supplied `333531988-BBMA-Home-Course.pdf` — strong product-linked teaching source;
3. accepted BBMA Finale / Missing Chapter material already indexed in the project;
4. user-supplied `BBMA technique.pdf` — historical corroboration;
5. ForexFactory `BBMA strategy by Oma Ally` thread — community corroboration only;
6. public BBMA teaching/manual mirrors — corroboration only.

Forum/web material never overrides a stronger uploaded/core source. Unsupported advanced claims are closed by rejection/non-authority rather than being promoted merely to eliminate a HOLD.

## 2. Closure principle

A Core gap is considered closed when one of the following is explicit and deterministic:

- `BBMA-ORIGINAL`: source rule is accepted as strategy Core;
- `BBMA-SOURCE-CONSISTENT`: bounded interpretation is accepted but not overstated as verbatim source;
- `PROJECT-EXTENSION`: deterministic EA mapping is permitted and labelled as project policy;
- `CONTEXT-ONLY`: source concept is retained but cannot create execution authority;
- `REJECTED`: an over-broad/literal/unsupported interpretation is explicitly not part of current Core.

`REJECTED` is a valid closure state. The project must not leave an unsupported rule perpetually ambiguous merely because a public source used broad teaching language.

## 5. C044 source vs deterministic EA mapping

The source principle is accepted:

`VALID DIRECTION -> RE-ENTRY -> continuation attempt -> NO MOMENTUM => TP/CLOSE`

and:

`VALID MOMENTUM => continuation survives -> wait for the next Re-Entry`.

For autonomous execution, the already-approved C044 mapping is retained as a conservative `[PROJECT-EXTENSION]`:

- require a fully closed owner-timeframe candle;
- require a direction-side outer-BB test before declaring failed continuation;
- same closed candle with canonical same-direction Momentum -> continue/wait next Re-Entry;
- outer-BB test without canonical Momentum -> latch full-position close;
- opposite reversal-confirmed Extreme on the same owner timeframe may terminate the old cycle;
- M20 emergency protection has precedence;
- no opposite auto-entry is implied.

The added outer-BB-test requirement is deliberately labelled deterministic project mapping, not a verbatim universal Oma Ally sentence.
