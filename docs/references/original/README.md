# Original BBMA Source Archive

This directory stores the original user-supplied BBMA source files used as the evidence/provenance layer for the BBMA Professional EA project.

## Stored original PDFs

- `Oma ally BBMA - AL.pdf` — primary operational BBMA reference.
- `BBMA technique.pdf` — secondary / corroborating historical BBMA reference.

These files must be preserved byte-for-byte. Do not edit, re-export, optimize, OCR-rewrite, or otherwise modify them in place. Any derived text, rule extraction, summary, reconciliation, or implementation specification belongs outside this directory under `docs/references/`.

Source precedence, provenance status, hashes, and retrieval policy are defined in `docs/references/SOURCE_INDEX.md`.
