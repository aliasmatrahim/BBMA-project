# BBMA Finale Original Subtitle Archive

This directory is reserved for the immutable original BBMA Finale V01–V07 subtitle files supplied by the user.

## Archive rules
- Store each raw subtitle file exactly as supplied.
- Keep the original supplied filename; do not rename the raw source.
- Do not normalize, correct, translate, merge, re-time, re-export, or overwrite an original file.
- Original filenames and SHA-256 hashes are recorded in `MANIFEST.md` and in `docs/references/video/oma_ally_finale/VIDEO_SOURCE_INDEX.md`.
- A file is not considered archived until its SHA-256 matches the recorded original hash.
