# Forex Factory BBMA Thread Archive

This directory records the external community thread `BBMA strategy by Oma Ally` from Forex Factory as supplemental BBMA evidence.

## Source role
- Classification: **COMMUNITY / SUPPLEMENTAL / NON-AUTHORITATIVE**.
- This thread may contain useful terminology, historical discussion, links, templates and community explanations.
- It must **not** override the original BBMA PDFs, archived BBMA Finale subtitles, accepted conflict decisions, or the canonical Strategy-Core specification.
- Individual forum claims are not treated as Oma Ally-authored rules unless independently corroborated by a higher-precedence source.

## Preservation policy
- Preserve the canonical thread URL and thread/post metadata.
- Store paraphrased evidence digests rather than copying large portions of copyrighted forum text.
- Keep post numbers, authors, dates and source links where relevant so evidence remains traceable.
- Record contradictions or unsupported claims instead of silently adopting them into BBMA Core.

## Files
- `SOURCE_RECORD.md` — thread identity, provenance and scope.
- `PAGE_01_EVIDENCE_DIGEST.md` — first-page high-value evidence digest.
