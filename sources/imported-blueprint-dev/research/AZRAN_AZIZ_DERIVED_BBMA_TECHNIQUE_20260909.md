The most useful lead is the apparent use of a large-TF storyline followed by a small-TF trigger. This can be compared against current project questions around premature entry, lower-TF child maturity, H1 confirmation age and the timing of F7 execution.

### 2. Re-Entry -> MHV -> lower-TF confirmation chronology
Public examples use sequences resembling:
`D1 Re-Entry -> H4 MHV -> H1 MHV -> lower-TF Death Cross`

Project handling:

- Treat the lower-TF crossover as an external derived trigger.

### 3. Trend-continuation versus reversal execution
The technique family appears to distinguish continuation/trending conditions from reversal/crossover conditions. This may be useful for testing whether the same lower-TF trigger behaves differently under:
- parent trend continuation,
- fresh MHV/Extreme transition,
- mature Re-Entry,
- failed-child chronology.

### 4. Invalidation / cut-loss research

Use only as a lead for source discovery and structured testing.
