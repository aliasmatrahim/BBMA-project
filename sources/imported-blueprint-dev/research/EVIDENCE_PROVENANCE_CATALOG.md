## Classification keys
- ACCEPTED-CORE: already supported by higher-precedence project evidence.

- DERIVED-PRACTITIONER: technique/rule family from an external practitioner using or extending BBMA concepts; useful for comparison/corroboration but not authoritative Oma Ally Core.

- TOOLING-TAXONOMY: term/logic is mainly evidenced by dashboards/scanners/products.
- COMMUNITY-CORROBORATION: repeated forum/community evidence, non-authoritative.
- NEED-PRIMARY-VIDEO: web/forum evidence cannot safely close executable semantics.
- REJECT-FROM-CORE: community/product/personal addition that must not be imported as Oma Ally Core.
